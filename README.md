
Vivek Khanke — Vue 3 Portfolio
===============================================

This is a deploy-ready Vue 3 skeleton built for quick deployment on Vercel / Netlify / GitHub Pages.

To run locally:
1. npm install
2. npm run dev

To build:
1. npm run build
2. The generated site will be in the `dist/` folder.

Notes:
- Replace `public/Vivek_Khanke_CV.pdf` with your actual CV PDF.
- Update content in src/components/* to customize text, links, and projects.
- Deploy to Vercel by importing this repo or uploading the ZIP.
